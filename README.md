# HUMANA · sitio web

Sitio estático (HTML + CSS, sin dependencias ni JavaScript) de HUMANA, consultoría en ética y gobernanza de IA para pymes y personas en Colombia.

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: servicios, frameworks Humano y Respeto, para quién, equipo y contacto |
| `privacidad.html` | Política de tratamiento de datos personales (Ley 1581 de 2012), en borrador |
| `css/tokens.css` | Tokens de marca v1.1. **No editar aquí**: la fuente de verdad está en el repositorio privado |
| `css/site.css` | Composición de página y correcciones documentadas sobre los tokens |
| `logo/` | Logos oficiales en SVG |

Los textos marcados como `[Pendiente…]` deben completarse antes de publicar.

## Publicación

Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
